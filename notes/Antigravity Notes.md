Four Step Framework: RAPS

1) Rules: Can set workspace level or project level. These rules tell the models what they should do and what they should not do. For example, we can set a rule that the model should always use terraform for infrastructure provisioning. 
2) Armoury: These are the tools that the models can use to perform their tasks. MCP Servers, Custom Tools etc.

Useful MCP Servers for Antigravity:
a) context7 MCP Server: It has the latest information about the tools and technologies available on the internet. 
b) firecrawl MCP Server: It crawls the internet and extracts the data from the websites. 
c) Pinecone MCP server: Store docs in vectorized forms for RAG retrieval on Pinecone database. It is a knowledge platform for AI agents. Fast, accurate retrieval that doesn't get more expensive as it scales.
